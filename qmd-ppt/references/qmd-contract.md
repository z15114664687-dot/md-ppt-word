# QMD 输入契约

推荐结构：

```yaml
---
title: "研究题目"
subtitle: "副标题"
author: "作者"
date: last-modified
format:
  pptx:
    slide-level: 2
---
```

参考母版 `shared-assets/ppt/research-reference.pptx` 由 `scripts/build_reference_pptx.py` 从 tokens 生成；`render_qmd_ppt.py` 渲染时自动注入（`--metadata reference-doc:<绝对路径>`），QMD 里**不需要**手写 `reference-doc`，也不要把绝对路径固化进 QMD。

## 语义层级

- 一级标题 `#`：章节过渡。
- 二级标题 `##`：一张内容页，必须写结论式标题。
- `.columns` / `.column`：原生多列。
- `.notes`：演讲备注。
- `.incremental`：仅在逐步揭示有必要时使用。
- 表格：优先 Markdown/Pandoc 原生表格；过宽表格拆分或移入附录。
- 公式：行内 `$x_t$`；陈列 `$$Y_{it}=\alpha+\beta D_{it}+\varepsilon_{it}$$`。

## 页面示例

```markdown
## 供需改善推动行业盈利在二季度拐点向上

:::: {.columns}
::: {.column width="64%"}
![行业收入与毛利率变化](figures/industry-profit.png)
:::
::: {.column width="36%"}
- 收入同比转正
- 供给增速放缓
- 毛利率连续两个季度改善

来源：Wind，公司公告；统计区间：2021Q1—2026Q2。
:::
::::
```

## 密度预算（对标研究报告/咨询风格）

- 正文列表不超过 8 项；每项尽量不超过 2 行。
- 正文字符建议不超过 600 个；超过 1200 个由预检直接报错。
- 每页 1 个主展项，最多 2 个辅助展项；信息密度向研报靠拢，但仍是一页一个主要判断。
- 标题保持单行；若无法单行，改写标题，不缩字。
- 图表或包含明显数据的页面必须有“来源：”或“资料来源：”。

## 版式硬约束（Pandoc pptx 写入器实测行为）

- **顶层表格或图片会独占一页**，其后的段落（如来源行）会被挤到无标题的延续页；图片与段落同页时还可能用重叠的占位符。因此内容页一律用 `.columns` 组织：图/表放一栏，要点列表放另一栏，**来源行写在栏内最后一段**，columns 之后不得再跟顶层段落。
- 表格放在栏内可正常渲染（继承母版表样式），纯文字页（段落+列表+来源）可不用 columns。
- **正文里不要用 LaTeX 公式**：PPTX 中的 OMML 数学会让 LibreOffice 把整个文本框渲染丢弃（内容还在 XML 里但预览不可见），真实放映环境兼容性也无保证。演示文稿中的公式改为文字表述；确需展示公式时先渲染成 PNG 图片。

## 卡片注入（突破占位符天花板）

Quarto/Pandoc 只会填占位符版式，做不了高密度卡片。`inject_cards.py`（在 `render_qmd_ppt.py` 里 quarto 渲染后自动运行）读下面这些 **raw block**（Pandoc 对 pptx 目标会丢弃它们，所以不会重复），按 `##` 页标题匹配，往对应页追加**原生、仍可编辑**的 shape。用于封面数字、结论、要点这类 Quarto 做得寡淡的地方；数据图表页照旧用 Quarto 原生渲染（真图表、可编辑）。

**结论条 takeaway**（浅红底 + 左红条 + 一句结论，落在页面底部）：

````markdown
## 拐点确认需要供需、盈利、估值三重同向

- 收入端同比转正…

```{=ppt-takeaway}
供需、盈利、估值三重同向确认，才把拐点写成结论 —— 单一信号不足以支撑
来源：Wind，作者整理。
```
````

**KPI 数字块 kpi**（一排浅红卡：品牌红大数字 + 灰标签，来源写块内，注入成卡下方小字）。KPI 页**只写这个块、不要再写正文/来源行**（会和卡片重叠）：

````markdown
## 组合三年表现一览

```{=ppt-kpi}
9.8%  | 年化收益
314%  | 累计收益
55.2% | 最大回撤
0.42  | 夏普比率
来源：Wind，作者测算；区间 2010—2025（模拟数据，仅作演示）
```
````

**卡片网格 cards**（一排 2–4 张内容卡：左红条 + 红色小标题 + 灰色描述，专治「三个要点/三种策略/三大风险」这类高密度概念页，是最接近手画卡片阵的版式）。同 KPI，页内**只写这个块**，来源写块内：

````markdown
## 拐点成立需要供需、盈利、估值三条腿同时落地

```{=ppt-cards}
供需侧 | 收入增速由负转正，行业订单与排产同步回升，需求侧首先确认
盈利侧 | 毛利率连续两个季度改善，费用率回落，盈利兑现进入验证期
估值侧 | 处于近五年 30% 分位以下，机构仓位偏低，估值端仍留有空间
来源：Wind，公司公告；作者整理（模拟数据，仅作演示）
```
````

**流程卡 flow**（①→②→③ 步骤卡，红箭头连接，替代手画流程图/SmartArt，适合筛选流程、方法步骤、时间线）：

````markdown
## 策略框架：从全 A 到目标持仓的三步筛选

```{=ppt-flow}
全 A 股票池 | 剔除上市不满三年的个股
三年次新股票池 | 全流通日落在上一年内；叠加财务指标过滤
目标持仓 | 季度调仓、等权买入
来源：作者整理
```
````

**对比卡 compare**（左右两张带色带表头的卡 + VS 徽章，适合改前 vs 改后、基准 vs 组合）。**最后一行是被强调的一侧**（红色表头，通常放"我们的/改后的"）；描述用 `；` 分隔，会拆成卡内多行 bullet：

````markdown
## 叠加交易手段：收益增厚、波动回撤双降

```{=ppt-compare}
纯三年次新 | 总收益 92.0%；年化波动 27.1%；最大回撤 34.5%
三年次新 + 交易手段 | 总收益 139.2%；年化波动 17.4%；最大回撤 20.9%
来源：Wind，作者测算
```
````

> 五种卡片块的来源都**必须写在块内**（`来源：…` 单起一行）。写成块外的顶层段落会被 Pandoc 塞进内容占位符并垂直居中，飘到卡片中间被盖住。

颜色/字体/字号全部来自 tokens，和母版品牌层一致。语法说明见 `scripts/inject_cards.py` 头部；「什么内容用什么版式」的决策表和版式取舍见 `references/slide-quality.md`。

## 不支持或需降级

- 交互式 HTML widget 不进入 PPTX。
- 复杂 Mermaid、嵌套多列、超宽表格先转为经过检查的 SVG/PNG。
- 不允许将整张幻灯片栅格化后塞进 PPTX。
