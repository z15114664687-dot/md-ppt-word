# 研究型 PPT 规则

## 字号与字体

全部字号以 `../../shared-assets/design-tokens.json` 的 `ppt.font_sizes_pt` 为唯一事实来源，本文件不重复抄写数值；两处不一致时以 tokens 为准。字号按研究报告/咨询风格的信息密度设定，不继承培训稿的演讲级大字号。层级角色：结束页、封面主/次标题、章节页标题、页面标题、封面元信息、核心判断、模块标题、正文、紧凑标签、时间轴标签、脚注（最小字号）。

字体名和角色以 tokens `ppt.font_profiles` 为唯一事实来源。普通中西文使用各档位的正文字体；`display_zh` **只**用于封面主标题和章节过渡页标题，不得扩散到正文或普通页标题。

## 版式角色

- 封面
- 章节过渡
- 单一结论 + 主图表
- 左图右结论
- 双图对比
- 全宽数据表
- 结论 + 依据 + 业务含义
- 流程 / 方法框架
- 风险提示
- 附录

不要堆叠网页仪表盘式卡片，不要用无意义图标和装饰图。每页按“结论 → 证据 → 解释 / 业务含义 → 来源”组织。

## 图表与表格

- 关键系列用 tokens `ppt.colors.primary`，其他系列用灰阶。
- 网格线弱化；不使用 3D 图表。
- 表头可用深红底白字，正文保持白底深灰字。
- 数字按小数位和量纲对齐；负数、风险项和关键差异可用红色。
- 图表标题、单位、区间放在展项上方；来源和备注放在下方。

## Logo 安全区

当前不可见，任何元素不得进入 `logo_slot`。未来仅在用户提供 logo 后启用 `enabled` 并替换母版命名锚点，正文无需重新排版。
