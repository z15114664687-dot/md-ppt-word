# 版式质量门禁

> Quarto 的 PPTX 输出天生只有一种版式（标题 + 内容占位符），不主动组织就会“简陋”。这份清单把简陋的四种典型讲清楚、给出重排方案，并说明哪些由 `validate_qmd.py` 机检拦截、哪些靠渲染后逐页 PNG 目检。改编自 slide-auditor 的版式审查清单，落到 QMD 语境。

## 〇、内容 → 版式决策表（写 QMD 前先对号入座）

“简陋”的根因是**把什么内容都塞进默认的标题+bullet 版式**。写每一页前，先判断这页要表达的是哪类内容，再选版式/卡片——这一步比事后修图更省力。图表页走 Quarto 原生；观点/数字/结论页用卡片注入（语法见 `qmd-contract.md`「卡片注入」）。

| 这页要表达 | 用什么 | 怎么写 |
| --- | --- | --- |
| **一排关键数字**（收益、回撤、规模…） | `{=ppt-kpi}` KPI 卡 | 每行写「数值 ＋ 竖线 ＋ 标签」，来源写块内；页内不再写正文 |
| **3–4 个并列要点 / 策略 / 风险 / 步骤** | `{=ppt-cards}` 卡片网格 | 每行写「小标题 ＋ 竖线 ＋ 一句描述」，来源写块内；页内不再写正文 |
| **一句必须记住的核心结论** | `{=ppt-takeaway}` 结论条 | 正文照写，末尾加结论条压在页底 |
| **筛选流程 / 方法步骤 / 时间线** | `{=ppt-flow}` 流程卡 | 每行「步骤名 ＋ 竖线 ＋ 说明」，①→②→③ 红箭头相连；替代手画流程图和 SmartArt |
| **改前 vs 改后、基准 vs 组合** | `{=ppt-compare}` 对比卡 | 两行「侧名 ＋ 竖线 ＋ 指标；指标；指标」，最后一行红头强调；指标用 ； 分隔成卡内 bullet |
| **图 + 解读** | `.columns` 左图右要点 | 图一栏（~60%）、≤4 条要点一栏（~40%），来源写栏内 |
| **两组图的对比** | `.columns` 双栏双图 | 图对比仍走双栏；纯指标对比用对比卡 |
| **一组数据指标** | `.columns` 内 Markdown 表 | 表放栏内（继承母版表样式），来源写栏内 |
| **结论 + 依据 + 含义**（纯文字页） | 段落 + bullet，可加结论条 | 结论加粗放大，依据降为灰阶；可加 `{=ppt-takeaway}` |
| **章节过渡** | `#` 一级标题 | 不要用 `##` 做只有标题的空白页 |

> 一句话原则：**先问“这是数字、并列项、流程、对比、结论、还是图表”，再落版式**。选对了，一页自然不简陋；选错了（比如把并列项写成一长串 bullet），再怎么调间距都像草稿。

标题节奏建议用卖方研报惯例的「栏目：结论」双段式（如“策略回测：三年累计跑赢基准约 190 个百分点”“风险提示：结论依赖历史统计与制度环境”）——冒号前是这页在报告里的角色，冒号后仍是可验证的结论，整套 deck 翻起来节奏一致。正面样例见 `shared-assets/examples/sample-deck.qmd`。

## 一、四种“简陋页”典型与重排方案

写完每一页，对照这四种典型自查；命中就按“重排”改，不要靠缩字或留白凑合。

| 简陋典型 | 为什么难看 | 重排方案 |
| --- | --- | --- |
| **顶层图独占页** —— 图片直接顶格，不在 `.columns` 里 | Pandoc 把顶层图片单独占一页，其后的来源行被挤到无标题的延续页；图片还常和占位符重叠 | 用 `:::: {.columns}`：图放一栏（宽 ~60%），要点列表放另一栏（~40%），**来源行写在栏内最后一段** |
| **纯 bullet 无展项** —— 整页只有一串列表 | 没有任何视觉锚点，像大纲草稿 | 给它配一个展项（图/表），或把列表改成一张 2–4 列的小表；实在只有文字，就精简成“结论 + 3 条依据”并让结论加粗放大 |
| **章节页大片空白** —— 用 `##` 做了只有标题的页 | 内容页占位符空着，视觉上一片惨白 | 章节过渡用 `#` 一级标题（走章节版式）；若确实是内容页，补一个关键数字、一句核心判断或一个展项 |
| **图左一长串 bullet 右** —— 双栏但右栏塞了 6+ 条 | 密度失衡、右栏读不完，等于把简陋搬进双栏 | 右栏收敛到 ≤4 条、每条 ≤2 行；把结论那条加粗或标红，其余降为灰阶依据 |

## 二、四类版式质量（渲染后逐页 PNG 目检）

机检拦不住的，渲染后一页一页看 PNG 确认：

- **溢出 Overflow**：文字掉出边界、表格/图超框、标题折行。修复顺序见第三节。
- **字号一致性**：同类页字号一致；不靠 `{.smaller}` / `font-size` 手动缩字（machine-checked，见第四节）；来源/脚注不低于 tokens `minimum`。
- **展项密度**：每页 1 个主展项，最多 2 个辅助展项；一页超过 2 张图/表就该拆页。
- **间距与对齐**：图表居中；栏间留白均衡；列表项之间不留多余空行。

## 三、间距优先修复原则（溢出时的顺序）

溢出**永远不要先缩字**。按这个顺序处理，缩字是最后手段：

1. **删减** —— 砍掉可推导、重复、次要的内容
2. **换版式** —— 单栏挤 → 改 `.columns` 双栏；4+ 并列项 → 考虑小表
3. **拆页** —— 一页两个判断 → 拆成两页，每页一个
4. **缩图** —— 图片宽度 100% → 80% / 70%
5. **缩字（最后手段）** —— 且不得低于 tokens `ppt.font_sizes_pt.minimum`

## 四、machine-checked 门禁（validate_qmd.py 自动拦截）

`python3 qmd-ppt/scripts/validate_qmd.py deck.qmd` 会拦下这些（error 阻断，warning 提示）：

| 检查 | 级别 | 说明 |
| --- | --- | --- |
| 顶层图片未包 `.columns` | **error** | 简陋头号成因，见第一节第 1 行 |
| `.columns` 之后还有顶层段落 | **error** | 来源行必须写进栏内；qmd-contract 硬约束 |
| 顶层表格未包 `.columns` | warning | 宽表可能挤走来源行 |
| 内容页近乎空白 | warning | 章节页大片留白，见第一节第 3 行 |
| `{.smaller}` / `font-size` 手动缩字 | warning | 违反“间距优先”，见第三节 |
| 标题 > 30 字 / 列表 > 8 项 / 正文 > 1200 字 / 缺来源 | error | 内容契约（原有） |

门禁只覆盖“可机检”的一半；第一、二节要靠人。**门禁全绿 ≠ 版式合格**——逐页 PNG 目检仍是交付前的必过项。

## 五、Pandoc pptx 写入器的已知脾气（渲染后确认）

- **双图对比页栏内的来源会被顶到图上方**：一栏里“图 + 来源段落”时，Pandoc 常把段落排在图片占位符之前，看起来是“来源在上、图在下”。介意顺序时把来源并进图注（`![标题](fig.png)` 的 alt 文字），或该页改用单图 + 右栏来源。这是写入器行为，不是 QMD 写错。
- 版式示范见 `shared-assets/examples/sample-deck.qmd`（KPI 卡、卡片网格、左图右结论、双图对比、全宽表、结论条、风险、附录表等角色，全部过门禁），可作为正面样例对照。
